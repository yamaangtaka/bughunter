Inicio rápidoQuick start

Úsalo sin complicacionesUse it without complexity

La ruta recomendada empieza con el diagnóstico local. Conecta un proveedor de IA únicamente cuando necesites una explicación o propuesta adicional.

The recommended path starts with local diagnostics. Connect an AI provider only when you need an additional explanation or proposal.

Instala y activaInstall and activate

Sube el ZIP desde Plugins → Añadir plugin → Subir plugin. Actívalo como cualquier otro plugin de WordPress.

Upload the ZIP from Plugins → Add Plugin → Upload Plugin. Activate it like any other WordPress plugin.

Abre ResumenOpen Summary

AI Bug Hunter lee el registro de errores disponible, identifica incidencias y muestra los elementos que requieren atención.

AI Bug Hunter reads the available error log, identifies incidents, and shows the items that require attention.

Ejecuta el análisisRun the analysis

Revisa el archivo, línea, severidad, evidencia y causa probable. El escáner de sintaxis puede funcionar sin IA.

Review the file, line, severity, evidence, and likely cause. The syntax scanner can work without AI.

Conecta IA, si hace faltaConnect AI if needed

En Ajustes, selecciona proveedor y modelo, agrega tu propia API key y autoriza expresamente la comunicación.

In Settings, select a provider and model, add your own API key, and expressly authorize communication.

Revisa y verificaReview and verify

Exporta el diff o expediente cuando exista. Haz la reparación manual en staging, valida PHP y vuelve a escanear.

Export the diff or case file when available. Perform the repair manually in staging, validate PHP, and scan again.

Funciones principalesCore features

Lo esencial del pluginThe plugin essentials

AI Bug Hunter organiza señales técnicas dispersas en un diagnóstico comprensible, con evidencia, historial y límites explícitos.

AI Bug Hunter turns scattered technical signals into an understandable diagnosis with evidence, history, and explicit boundaries.

Registro y sintaxisLogs and syntax

Lee errores PHP, agrupa incidencias repetidas y comprueba si los archivos pueden ser interpretados por PHP.

Reads PHP errors, groups repeated incidents, and checks whether PHP can parse the files.

Evidencia verificableVerifiable evidence

Muestra rutas, líneas, contexto, huellas SHA-256 y datos que ayudan a confirmar que el archivo revisado no cambió durante el análisis.

Shows paths, lines, context, SHA-256 fingerprints, and data that help confirm the reviewed file did not change during analysis.

Historial y expedientesHistory and case files

Conserva resultados, estado, consumo estimado, respaldos locales relacionados y expedientes descargables.

Keeps results, status, estimated usage, related local backups, and downloadable case files.

Análisis opcional con IAOptional AI analysis

Solicita hipótesis, causa raíz, evidencia clave, riesgo y una propuesta revisable utilizando la cuenta del administrador.

Requests hypotheses, root cause, key evidence, risk, and a reviewable proposal using the administrator’s account.

Diff y guía manualDiff and manual guide

Cuando hay evidencia suficiente, presenta o exporta diferencias línea por línea. Si no, entrega una guía segura sin inventar un parche.

When evidence is sufficient, it presents or exports line-by-line differences. Otherwise, it provides safe guidance without inventing a patch.

Comparación oficialOfficial comparison

Puede comparar o restaurar archivos del núcleo usando fuentes oficiales de WordPress.org cuando el administrador lo solicita.

Can compare or restore core files from official WordPress.org sources when requested by the administrator.

IA y privacidadAI and privacy

Tú decides cuándo comunicarYou decide when to communicate

No se envía información a un proveedor de IA por defecto. La conexión necesita proveedor, modelo, API key propia y consentimiento explícito guardado por un administrador.

No information is sent to an AI provider by default. Connection requires a provider, model, your own API key, and explicit consent saved by an administrator.

Datos que puede enviarData it may send

  • Fragmentos relevantes del archivo relacionado.Relevant excerpts from the related file.
  • Mensajes de error y evidencia de ejecución.Error messages and runtime evidence.
  • Rutas relativas, líneas y metadatos técnicos.Relative paths, line numbers, and technical metadata.
  • Instrucciones escritas por el administrador.Instructions written by the administrator.

Protecciones aplicadasApplied protections

  • Intenta ocultar claves, tokens, correos e IP detectables.Attempts to redact detectable keys, tokens, emails, and IP addresses.
  • Guarda la API key cifrada cuando el servidor lo permite.Stores the API key encrypted when the server supports it.
  • Bloquea solicitudes si no existe consentimiento.Blocks requests when consent is missing.
  • Exige HTTPS para endpoints públicos personalizados.Requires HTTPS for custom public endpoints.

La redacción reduce el riesgo, pero no garantiza anonimato total.Redaction reduces risk but does not guarantee complete anonymity.

Antes de autorizar un análisis externo, revisa las políticas del proveedor y evita enviar secretos o información personal que no sea necesaria.

Before authorizing external analysis, review the provider’s policies and avoid sending secrets or personal information that is not necessary.

Límites de la ediciónEdition boundaries

Qué hace y qué no haceWhat it does and does not do

La edición WordPress.org está diseñada para análisis y orientación. Distingue las propuestas externas de las acciones locales y deterministas solicitadas por el administrador.

The WordPress.org edition is designed for analysis and guidance. It separates external proposals from local deterministic actions requested by the administrator.

Sí puedeIt can

  • Analizar errores, archivos y evidencia local.Analyze errors, files, and local evidence.
  • Solicitar explicaciones y propuestas a un proveedor autorizado.Request explanations and proposals from an authorized provider.
  • Presentar o exportar un diff revisable.Present or export a reviewable diff.
  • Generar reportes y una guía de reparación manual.Generate reports and a manual repair guide.
  • Ejecutar acciones locales deterministas solicitadas, como comparar/restaurar núcleo oficial o revertir desde un respaldo local.Run requested local deterministic actions, such as comparing/restoring official core files or reverting from a local backup.

No puedeIt cannot

  • Aplicar automáticamente una reparación generada por IA.Automatically apply an AI-generated repair.
  • Habilitar esa función mediante licencia, ajuste, firma o política remota.Enable that function through a license, setting, signature, or remote policy.
  • Garantizar que una propuesta de IA sea correcta.Guarantee that an AI proposal is correct.
  • Sustituir staging, respaldos completos o revisión técnica competente.Replace staging, full backups, or competent technical review.
  • Enviar reportes automáticamente al desarrollador.Automatically send reports to the developer.

FAQ

Preguntas frecuentesFrequently asked questions

Respuestas directas para las dudas más comunes al instalar y utilizar la edición pública.

Direct answers to the most common questions when installing and using the public edition.

¿Necesito una API para usar el plugin?Do I need an API to use the plugin?
No. El diagnóstico local, la lectura de registros y varias comprobaciones funcionan sin IA. La API solo se necesita para solicitar análisis adicional a un proveedor externo.No. Local diagnostics, log reading, and several checks work without AI. An API is only required to request additional analysis from an external provider.
¿El plugin repara automáticamente el código?Does the plugin repair code automatically?
No en esta edición. Las propuestas generadas por IA se muestran o exportan para revisión. La reparación debe realizarse manualmente fuera del plugin, preferentemente en staging.Not in this edition. AI-generated proposals are shown or exported for review. The repair must be performed manually outside the plugin, preferably in staging.
¿Qué ocurre si no puede crear un diff confiable?What happens if it cannot create a reliable diff?
Mantiene el diagnóstico, explica qué evidencia falta y ofrece pasos de verificación. No inventa un parche únicamente para entregar una respuesta.It keeps the diagnosis, explains what evidence is missing, and provides verification steps. It does not invent a patch just to produce an answer.
¿La API key queda visible?Is the API key visible?
El campo no vuelve a mostrar la clave guardada. El plugin intenta cifrarla antes de almacenarla, o puede leerla desde la constante ABH_API_KEY para no guardarla en la base de datos.The field does not display the saved key again. The plugin attempts to encrypt it before storage, or it can read it from the ABH_API_KEY constant so it is not stored in the database.
¿Puedo usar un modelo local?Can I use a local model?
Sí, mediante un servidor compatible con OpenAI. Los endpoints privados o localhost requieren autorización adicional y la URL debe configurarse de forma explícita.Yes, through an OpenAI-compatible server. Private endpoints or localhost require additional authorization, and the URL must be configured explicitly.
¿Qué debo hacer después de una propuesta?What should I do after receiving a proposal?
Revisar el contexto y el diff, crear un respaldo completo, aplicar el cambio manualmente en staging, validar sintaxis PHP, probar la función afectada y ejecutar un nuevo escaneo.Review the context and diff, create a full backup, apply the change manually in staging, validate PHP syntax, test the affected feature, and run a new scan.
